# 周报

## 两种用法

**从台账生成**:读项目台账,取本周有变更的行(按「变更日志」的时间筛),按项目归并。
**润色草稿**:使用者给一段草稿,只改表达。

## 从台账生成

```
<姓名> 周报 · <起始日> 至 <结束日>

<项目一>
  本周完成:  事项 —— 完成依据
  本周推进:  事项 —— 从哪一步到哪一步
  下周计划:  事项 —— 截止日(台账里没有正式期限就写"待定")
  需要支持:  在等什么,需要谁

<项目二>
  ...

其他事项
```

规则:

- 「本周完成」只收台账里状态改成 `已完成` 且有 `完成依据` 的。
- 「本周推进」写状态或阶段发生过变化的,要说清从哪到哪。只是"持续跟进"而无变化的
  不要写进周报充数。
- 「需要支持」对应台账里的"等…"状态和「待决事项」。周报是这些事第二次被看到的
  地方,漏掉它们就只能等下次会议。
- 本周无变更的项目写一行"无变化",不要省略整个项目 —— 看报的人需要知道它还在。

## 润色草稿

只做这些:

- 把口语整理成陈述句;合并重复的话;统一时间和数字格式
- 把模糊的动词换成具体的(「跟进了设备的事」→ 使用者原文里有的那个具体动作)

不做这些:

- 不新增事实。草稿里没有的工作、没有的数字、没有的时间,一个都不要加
- 不把"大概""可能"改成确定语气。那不是表达问题,是事实本身不确定
- 不夸大。「配合完成」不要改成「主导完成」
- 不删减困难和未完成项。周报里的"卡住了"是有用信息

润色后若发现草稿与台账不一致,**指出来**,不要径自按台账改写:可能是台账漏记,也可能
是草稿记错,这要使用者判断。
